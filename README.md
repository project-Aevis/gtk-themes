# Aevis GTK Themes

Matching GTK 3 and GTK 4 themes to provide a unified visual experience for GTK applications running under the Aevis Desktop Environment.

Part of the **[Project Aevis](https://github.com/project-Aevis)** suite.

## Variants

- `Aevis-light`
- `Aevis-dark`
- `Cutefish-light` / `Cutefish-dark` (legacy compatibility)

## Build and Install

```shell
mkdir build
cd build
cmake -DCMAKE_INSTALL_PREFIX=/usr ..
make
sudo make install
```
